# 答题题库

`questions.txt` 为 UTF-8 文本，由 `scripts/quiz/QuestionBank.cs` 在运行时读取。一行一题，使用制表符分隔以下字段：

```text
分类    科目    题目    A选项    B选项    C选项    D选项    正确答案    解析
```

正确答案使用 `A`、`B`、`C`、`D`；解析可留空。字段内的换行写作 `\n`，反斜杠写作 `\\`。运行时会按钱包中的种子打乱题目顺序并记录答题进度。
